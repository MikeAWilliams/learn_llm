Byte-Pair Encoding (BPE)
solidgoldmagikarp was a magic word that broke gpt-2 and gpt-3 becasue it was in the vocabulary, but hardly in the training set. This lead to strange behavior.

https://www.lesswrong.com/posts/aPeJE8bSo6rAFoLqg/solidgoldmagikarp-plus-prompt-generation

https://tiktokenizer.vercel.app/
This app shows how any given string breaks into tokens for many LLMs

Byte-Pair Encoding algorithm is a way to represent strings as utf-8 byte streams and then compress them into tokens.
https://en.wikipedia.org/wiki/Byte-pair_encoding
